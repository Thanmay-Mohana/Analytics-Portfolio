# The Insight Stack: Power BI, Layer by Layer

## From Business Questions to Trusted Decisions

This repository contains the complete 12-week **Power BI, Layer by Layer** series from *The Insight Stack*.

The series follows the Power BI journey from understanding business requirements and connecting data through data preparation, modelling, DAX, report design, advanced analytics, performance, governance, and finally decision systems.

> The 12-week journey is intended as a practical foundation and learning framework rather than an exhaustive guide to every Power BI capability.

## What This Series Covers

The series explores Power BI as more than a dashboarding tool.

It covers how analysts can move from:

**Business Question → Trusted Data → Reliable Model → Clear Insight → Governed Access → Informed Action**

Topics include:

- Business and functional requirements
- Power BI data connections
- Power Query and data preparation
- Data profiling and quality
- Data modelling and relationships
- DAX measures and calculations
- Report and visual design
- Interactive storytelling
- Advanced analytics
- Performance optimisation
- Security and governance
- Decision systems and automation
